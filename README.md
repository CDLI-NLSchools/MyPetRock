# My Pet Rock

A single-file designer studio for Grade 7 STEAM, Explore the Land, Lesson 3 Extension. It replaces a Jamboard extension activity that no longer works.

Students choose a pet rock (two rocks cropped from the original board, or a photo of a real rock they found and decorated at home, read locally in the browser only), decorate it on a drawing canvas with paint, marker, and highlighter tools, place it in one of five scenes cropped from the original board (forest, racetrack, ocean, store, rock pile), and answer the board's closing questions: name, distinguishing characteristics, rock family, and how the rock formed. The finish is a printable pet rock card with the composed portrait (scene, rock, and pen strokes composited on a canvas) plus the four answers, with Print and Copy buttons.

Formative only: nothing is scored, nothing is submitted anywhere, and nothing leaves the student's browser. Single HTML file with the artwork embedded, no external resources, works offline.
